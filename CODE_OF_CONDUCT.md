# Rules for Behavior

We want a project where engineers help each other. These rules apply in all spaces of the project: issues, pull requests, discussions and reviews.

## What we need from you

- Be polite and be exact. Give the cause of your opinion.
- Comment on code and ideas. Do not attack persons.
- Accept feedback. Give feedback that a person can use.
- Help new contributors. Each person was new one time.

## What we do not accept

- Insults, threats or harassment.
- Attacks on a person, or the publication of the private data of a person.
- Spam and advertisements that are not related to the project.
- Behavior that a reasonable person sees as not professional.

## When a person breaks the rules, we do this

The maintainers remove comments, close threads and stop persons that break these rules. To report a problem, use the private reporting feature of GitHub, or use the contact in [SECURITY.md](SECURITY.md). We keep each report private, and we examine it carefully.
